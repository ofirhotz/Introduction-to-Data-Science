## 🛠️ Technical Skills Demonstrated

* **Data Engineering & Analysis:** Data wrangling, handling missing values, outlier detection, statistical profiling (`Pandas`, `NumPy`).
* **Web Scraping & Extraction:** Extracting web data, HTML parsing, handling pagination (`BeautifulSoup`, `requests`).
* **Machine Learning Pipelines:** Supervised learning algorithms, regression analysis, feature scaling, model evaluation (`Scikit-Learn`).
* **Data Visualization:** Distribution plots, correlation heatmaps, feature relations (`Matplotlib`, `Seaborn`).
* **Model Validation:** K-Fold Cross-Validation, train-test splitting, metrics optimization (Precision, Recall, F1, MSE, $R^2$).
